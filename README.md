# Hollow Valley · 空空山谷

陶瓷作品网站，包含品牌插画、英文故事、真实产品照片和逐帧动画。

## 发布

GitHub Pages：Settings → Pages → Deploy from a branch → main → /docs。
网站内容保存在 `docs/`；提交并推送修改后自动发布。

## 持续上新

1. 双击 `打开作品管理.command`。
2. 浏览器打开 http://127.0.0.1:4174/studio 。
3. 上传封面或连续角度照片，填写作品名称、介绍，设置展示状态和顺序。
4. 保存到本机，预览确认，然后提交并推送到此仓库。

作品信息：`docs/products.json`；图片：`docs/assets/`。
管理页只在本机运行，备份不会提交到 GitHub。
